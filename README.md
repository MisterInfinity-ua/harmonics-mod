# HARMONICS

> **Harmonics** is a Minecraft mod (Fabric + NeoForge) that adds a complete system of **tiered musical instruments** and **resonant combat weapons**, full **armor sets** across many materials, an item-**fusion** mechanic, and its own set of **ore world generation**.

---

## Core Features

### Musical Instruments
* **5 instrument types:** Flute, Drum, Horn, Chimes, and Lute.
* **Playable tiers** across a wide range of materials.
* **AoE effects:** right-click to trigger unique area-of-effect abilities (Regeneration aura, Fire Resistance, Slowness pulses, or Haste buffs).

### Combat Weapons
* **Combat types:** Swords, Axes, Shovels, and Pickaxes.
* **A broad range of materials and tiers**, from early game up to exotic late-game materials.
* **On-hit & active abilities:** Fire Aspect, Explosive Inferno, Soul Steal, Void Teleportation, and right-click AoE special attacks (per-material).

### Armor
* **Full armor sets** (helmet, chestplate, leggings, boots) across all materials, with matching equipment-layer textures.

### Masterwork Fusion System
Craft **two identical base items** together in any crafting grid to create a **Masterwork** version:
- **Instruments:** Doubled effect range and potency with a glowing texture.
- **Weapons:** Increased damage and doubled special-effect strength.

### Multiple Materials & Ore Worldgen
- Many material sets are obtainable by mining the mod's own ores, which generate naturally in the overworld.
- Example material: **Ruby** — a gemstone with tools, weapons, a full armor set, and a Masterwork line.
- Rubies can also be found in **village chests**.

> The exact set of materials and total item count grows with every release. See the **Releases** tab and the [changelog](CHANGELOG.md) for the current contents.

### HD Textures (32x)
Harmonics ships an optional **Harmonics 32x** resource pack (2x upscaled textures matching the style of the *Faithful 32x* pack):

- **Fabric:** the pack is bundled inside the mod jar. Open the resource-pack screen and enable **"Harmonics 32x"** (it is off by default).
- **NeoForge / any loader:** a standalone `packs/Harmonics32x.zip` is included in the repository and with releases — drop it in your `.minecraft/resourcepacks` folder and enable it.

Enable **Harmonics 32x** together with **Faithful 32x** for a consistent 32x look. The mod's base textures stay 16x, so nothing changes if the pack is off.

## Installation

1. Download the latest **Harmonics** `.jar` for **Fabric *or* **NeoForge** from the **Releases** tab.
   - Pick the loader you use; both jars ship with every release.
2. Place the file inside your `.minecraft/mods` folder.
3. Launch the game — all items appear in the Harmonics creative tab.

### Technical Overview
- **Mappings:** Official Mojang (Mojira) mappings.
- **Asset generation:** Textures and item models are generated by Python scripts in this repo (`generate_assets.py`, etc.).
- **Project layout:** Shared resources in `src/` driven by both loader builds; NeoForge specifics under `neoforge/`.

### Building
```bash
# Fabric build:
./gradlew build -x test

# NeoForge build (from the neoforge/ subproject):
cd neoforge && ./gradlew build -x test
```
